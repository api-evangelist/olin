# Olin Corporation — removed at the trademark holder's request

Removal was requested on **2026-09-10** via a trademark complaint relayed by GitHub Trust
& Safety, and was honored. (GitHub reviewed the report and found no violation of its
trademark policy; the removal is a courtesy to the rights holder, not a compelled action.)

Everything derived is deleted: the API descriptor, scoring history, and all artifacts.
The repository remains only as this notice so existing inbound links do not break.

On apis.io, Olin keeps a minimal record — the company name, a one-line description, and a
link to [olin.com](https://www.olin.com/) — and is **unrated**: no score of any kind.

Olin is on the permanent delisting registry
([`network/_data/delisted.yml`](https://github.com/api-search/network/blob/main/network/_data/delisted.yml)),
which every harvest, enrichment and scoring pipeline consults before touching anything.

Removal requests are honored on request: kin@apievangelist.com.
